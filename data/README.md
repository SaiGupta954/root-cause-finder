# Data

Only public data goes here. Never put logs from work in this folder or anywhere in this repo.

- `samples/`: small logs from the failure lab that visitors can try in one click (Week 3).
- Loghub logs: run `./scripts/download_loghub.sh` (they are git-ignored).

Loghub is free for research and academic use. Cite it:

> Jieming Zhu, Shilin He, Pinjia He, Jinyang Liu, Michael R. Lyu. *Loghub: A Large Collection of System Log Datasets for AI-driven Log Analytics.* IEEE ISSRE, 2023. https://github.com/logpai/loghub
