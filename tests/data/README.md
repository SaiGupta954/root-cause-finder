# Test fixtures

Small hand-written logs for unit tests only. They are **not** failure-lab data and are never used in the
evaluation numbers.

| File | What it is |
|------|------------|
| `normal_20.log` | Hand-written healthy syslog (cron, ssh logins). |
| `disk_full_40.log` | Generated by a few lines of Python in Week 1: normal cron traffic, then "No space left on device" errors. |
| `ssh_bruteforce_30.log` | Hand-written in the format of Loghub's OpenSSH log, reusing its host name (`LabSZ`) and one attacker IP. The lines are not copied from Loghub. |

Real public logs (Loghub) are downloaded into `data/` by `scripts/download_loghub.sh`.
Failure-lab logs (real container runs) live in `data/failure_lab/`.
